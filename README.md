# Wedding Invitation

A wedding invitation website and a short animated invitation film.

**Website:** https://parthchavannn.github.io/weddinginvite-ss/

## Files

| File | Description |
|---|---|
| `index.html` | The invitation website |
| `video.html` | The animated invitation film |
| `wedding-invite.mp4` | The rendered film |

## Viewing

Open `index.html` in any modern browser. For the film, open `video.html` in a recent Chrome or Edge on a computer.

Built with plain HTML, CSS and JavaScript. No build step.
